# DST — Developmental Stability Theory of Predictive Hierarchies

Simulation code for the manuscript:

> *A Developmental Stability Theory of Predictive Hierarchies: Why Some
> Perceptual Architectures Remain Stable Under Perturbation.*

This repository regenerates every display item in the article — main-text
Figures 1–8 and Supplementary Figures S1–S7 — from the equations stated in
the paper (main text Eqs. 1–21; Supplementary Eqs. S1–S8).

## Quick start

```bash
pip install -r requirements.txt
python scripts/make_all.py        # regenerates all 15 figures (~1 min)
```

Figures are written to `figures/` as 300-dpi PNGs. Each figure can also be
regenerated individually, e.g. `python scripts/make_figure5.py`.

## Repository layout

| Path | Contents |

| `dst/binding.py` | Temporal binding windows under Bayesian causal inference; w* ∝ σ_t (Eq. 15) |
| `dst/neuron.py` | Reduced two-point pyramidal neuron; NMDAR hypofunction at two sites; factorial measurement of κ and η; the composed cascade f → (κ, η) → σ → S (Eqs. 18–20; S3–S7) |
| `dst/cohort.py` | The three observables (CMI, leak slope, responsivity), four candidate mechanisms, leave-one-out model recovery, mixture estimation (Eq. S8; §§S6–S8) |
| `dst/course.py` | Ornstein–Uhlenbeck gain fluctuation plus the plasticity ratchet dσ/dt = ρ·max(0, −S)(1 − σ/σ_max) (Eq. 21) |
| `dst/hopfield.py` | Hopfield illustration of spurious-attractor proliferation (§S1) |
| `scripts/make_figure*.py` | One self-contained script per figure |

## Figure ↔ script map

`make_figure1.py` … `make_figure8.py` → main-text Figures 1–8;
`make_figureS1.py` … `make_figureS7.py` → Supplementary Figures S1–S7.

## Parameters, seeds, and reproducibility

All stochastic simulations use fixed seeds, so `make_all.py` is exactly
reproducible. As stated in the manuscript (§3.7), the constants involved —
the neuron calibration in `dst/neuron.py`, the hierarchy profiles
(σ_struct, D, g) in `make_figure5.py`, the lumped constant c, and the
cohort noise levels — are **illustrative calibrations chosen to place an
intact hierarchy in the stable regime, not parameters estimated from
data**. The neuron calibration is fitted so the measured dendritic
coefficients reproduce the worked example of §3.7 (κ = 1.66, η = 0.21 at
f = 1; κ = 0.25, η = 0.74 at f = 0.5). What is structural rather than
tuned — the direction of the coefficient changes, the interior leak
optimum, the D-dependence of the crossing — is exactly what the robustness
sweep (`make_figureS4.py`, 10,000 parameter sets) checks.

Headline quantities regenerated by this code: the simulated stability
boundary coincides with gσ√D = 1 with no free parameters (Figure 1);
belief-space divergence occurs at the same threshold (Figure S2); κ falls
and η rises non-monotonically in ≈98–100% of 10,000 random parameter sets
(Figure S4); leave-one-out mechanism recovery is 90% overall with apical
decoupling recovered at 100% and residual error confined to the
intact-versus-noise boundary (Figure 6); a mixed cohort's mechanism
proportions are recovered essentially exactly, with N ≈ 100 sufficing for
±10% on the apical fraction (Figure S5); identical gain noise yields
remitting, relapsing, and declining courses (3, 4, and 7 episodes) as only
the ratchet rate ρ varies (Figure 7).

## Requirements

Python ≥ 3.9 with `numpy`, `scipy`, and `matplotlib` (see
`requirements.txt`). No GPU, no data downloads: the article uses no
empirical data, and every figure is generated from the model equations.
